# Changelog

All notable changes to this project will be documented here. The entries below describe **development milestones**, not separately published GitHub releases.

## [0.5.4] — 2026-11-13

### Fixed
- Constrained zoomed artwork to the intended character sheet area.
- Preserved interactive sheet controls while displaying a continuous background layer.

### Included
- Individual character sheet image selection and reset.
- Zoom, horizontal and vertical positioning, gradient strength, and live preview.
- Per-character persistence using Actor flags.
- Missing-image validation with a default-background fallback.

## [0.5.3] — Development milestone

### Changed
- Moved artwork rendering to CSS, avoiding additional HTML nodes in character sheets.
- Added image availability checks and a fallback to the default appearance.

## [0.5.2] — Development milestone

### Fixed
- Adjusted artwork stacking to restore interaction with native sheet controls.

## [0.5.1] — Development milestone

### Added
- Continuous custom image rendering and live appearance controls.
